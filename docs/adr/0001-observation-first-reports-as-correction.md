# 기상청 실황을 1차 콘텐츠로, 유저 제보를 보정 레이어로 둔다

유저 제보를 1차 콘텐츠로 삼으면 출시 첫날 지도가 비어 있어 앱이 죽은 채로 시작한다. 그래서 기상청
초단기실황을 기본 콘텐츠로 깔고, 제보는 그 위에 "지금 여기는 다르다"를 덮어쓰는 레이어로 정의했다.
제보가 0건이어도 앱은 정상 작동하며, 제보가 쌓일수록 좋아진다.

## Consequences

- 비교 기준은 예보가 아니라 **초단기실황**(`getUltraSrtNcst`)이어야 한다. 예보는 시제가 달라 제보와
  나란히 놓으면 "예보가 틀렸다"가 아니라 "시간대가 다르다"가 되어 버린다.
- 메인 화면은 지도가 아니라 현재 위치 날씨 카드다. 지도는 "왜 다르지?"를 확인하는 2차 탭이다.
- 기상청 API 키는 앱 번들에 넣을 수 없어 Edge Function 프록시가 필수다. 기상청은 위경도가 아닌
  자체 LCC 격자(nx, ny)를 쓰므로 변환과 격자 단위 캐시가 서버에 필요하다.

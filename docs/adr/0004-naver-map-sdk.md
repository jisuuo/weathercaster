# 지도는 네이버 지도 SDK를 쓴다

한국은 지도 데이터 국외 반출 규제 때문에 구글 지도의 한국 커버리지가 반쪽이다. `react-native-maps`를
쓰면 iOS는 Apple 지도로 정상이지만 Android는 구글 지도라 같은 앱의 지도 품질이 OS별로 달라진다.
네이버와 카카오를 비교한 결과 네이버를 택했다.

## Considered Options

- **카카오 지도** — RN 래퍼(`@react-native-kakao/map`)가 네이버 래퍼와 같은 곳(MJ Studio)에서 나온다.
  "네이버만 RN 지원이 있다"는 것은 사실이 아니다. 다만 2026-07-21 무료 쿼터 정책 변경 직후라 활성화
  절차(비즈월렛 연결 등)가 덜 안정적으로 보였다.
- **react-native-maps** — Expo Go에서 바로 굴릴 수 있어 초반이 빠르지만, Android 한국 지도 품질을
  포기해야 한다.

즉 네이버의 우위는 지도 품질이나 비용이 아니라 **RN 세팅이 덜 아프다는 것 하나**다
(`@mj-studio/react-native-naver-map` v2.9.0, Expo config plugin 문서 완비).

## Consequences

- 비용은 결정 요인이 아니었다. 네이버 Mobile Dynamic Map의 과금 단위는 API 호출이 아니라 지도 뷰 생성
  1회(`onCreate`)이고, 지도가 2차 탭인 이 앱에서는 호출량이 작다. 대표계정에 API별 월 최소 3,000건 ~
  최대 1억 건의 무료 제공량이 있다. 다만 **양사 모두 모바일 SDK의 무료 제공량을 공개 문서에 명시하지
  않으므로 콘솔에서 직접 확인해야 한다.**
- 100m 격자 스냅을 쓰기로 해서 역지오코딩이 필요 없다. 실제로 돈이 새는 항목이 0이다.
- 시작부터 development build가 필요하다. 어차피 푸시 알림 때문에 Expo Go를 벗어나야 하므로 추가 비용은
  아니지만, 초기 세팅 순서가 달라진다.
- 지도 컴포넌트는 어댑터 한 파일로 감싸서 교체 비용을 낮춘다.
